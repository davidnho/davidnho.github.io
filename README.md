# Noel S. David — Data Engineering Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — complete portfolio website, including the CleanDataPro live project card with its applied skills and technology tags.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Extract this ZIP and upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Visit `https://YOUR_GITHUB_USERNAME.github.io/` after deployment completes.

## Before publishing
- Replace `YOUR_GITHUB_USERNAME` in the GitHub link near the Contact section.
- Check the contact details and LinkedIn URL.
- Review the employment dates and descriptions against your latest resume.
- Add your actual project summaries, repository links, screenshots, and demos in the Projects section. The current project cards are clearly marked as placeholders.

## Customization
All styling and JavaScript are included in `index.html`; no build tools, frameworks, or package installation are required.


The `assets/CleanDataPro.xlsm` file is the downloadable Excel VBA data-cleaning project linked from the portfolio page. Keep this file in the `assets` folder when publishing to GitHub Pages.
