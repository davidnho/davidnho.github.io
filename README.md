# Noel S. David — Data Engineering Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — complete portfolio website, including the CleanDataPro live project card with its applied skills and technology tags.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Extract this ZIP and upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Visit `https://YOUR_GITHUB_USERNAME.github.io/` after deployment completes.

## Before publishing
- Replace `YOUR_GITHUB_USERNAME` in the GitHub link near the Contact section.
- Check the contact details and LinkedIn URL.
- Review the employment dates and descriptions against your latest resume.
- Add your actual project summaries, repository links, screenshots, and demos in the Projects section. The current project cards are clearly marked as placeholders.

## Customization
All styling and JavaScript are included in `index.html`; no build tools, frameworks, or package installation are required.




The portfolio also features the Customer Analysis Dashboard on Tableau Public. The project card links to the published Tableau visualization and lists the relevant visualization and analytics skills.


## Power BI project

The portfolio includes the Coca-Cola Sales Dashboard — 2022 project card. Keep `assets/Coca_Cola_Sales_Dashboard_2022.pbix` in the `assets` folder so visitors can download the Power BI report. The card credits the Kenji Explains tutorial that inspired the project and notes that the colors and visual settings were customized.


## Sales Analytics Excel Lab

The portfolio includes a downloadable Excel workbook at `assets/Sales_Analytics_Excel_Lab.xlsm`. Keep this file in the `assets` folder when publishing to GitHub Pages.


## Theme switcher

The portfolio includes a Dark / System / Light theme selector in the header. The selected preference is saved in the visitor's browser using local storage. System mode follows the device's color-scheme preference.


The theme selector is positioned on the right side of the navigation bar.
